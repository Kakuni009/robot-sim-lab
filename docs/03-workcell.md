# 作業セルの設定とUSD保存

[目次へ](README.md)

## 今回作ったもの

Franka Pick Placeのロボットと部品に、供給場所・運搬先を示す薄い目印を追加した。
今回はGUI操作で作成し、Pythonスクリプトによるシーン生成はまだ行っていない。

Create > Mesh > CubeでMeshを作り、Stageで名前を変更してTransformを設定した。
元の `Cube` は運搬する部品なので、そのまま残した。

| 名前 | Translate (X, Y, Z) | Scale (X, Y, Z) |
|---|---|---|
| SupplyMarker | (0.5, 0, 0.001) | (0.15, 0.15, 0.002) |
| TargetMarker | (0, 0.5, 0.001) | (0.15, 0.15, 0.002) |

Orientはすべて0。Scaleは倍率で、Translateはこのシーンではm単位。
確認した作成直後のMeshのPointsには±0.5の座標が表示されており、
1 m角のメッシュなら上記Scaleで15 cm角・厚さ2 mmとなる。
SupplyMarkerのPrim Pathは画像上 `/SupplyMarker`。Worldを選択して作成しても、
今回の結果は `/World/SupplyMarker` ではなかった。

目印に重力や衝突判定を追加する操作は行っていない。
ロボットは目印を認識して動くのではなく、サンプル内の座標に従う。
目印だけを動かしても運搬先は変わらない。

## 動作確認

Cubeの開始位置を `(0.5, 0, 0.02575)` に設定し、START PICK PLACEで運搬した。
ユーザーが運搬成功を報告。置いた直後にCubeが少し動いたが、変位や静止時間は未測定。
繰り返し試験や配置精度の評価はまだ行っていない。

## 保存ファイル

- [pick-place-baseline.usd](../pick-place-baseline.usd): 目印追加前の初期配置として保存を案内したもの。
- [workcell-v01.usd](../workcell-v01.usd): 目印追加後、停止してCubeを初期位置へ戻し、保存を案内したもの。

ユーザーが保存完了を報告し、両ファイルの存在はローカルで確認済み。
保存内容の内部配置、参照アセットの解決、再オープン後の動作は未検証。

USDはシーンを記述する形式。配置・形状・物理設定などを保持できるが、
実行中のPythonインスタンスや、サンプルUIのボタン処理を丸ごと保存するものではない。
外部アセットへの参照を含む場合があり、ファイル単体で別PCへ移せるとは限らない。
